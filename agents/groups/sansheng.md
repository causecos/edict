# 三省組級指令 — 太子、中書省、門下省、尚書省共用

> 本文件包含三省（協調角色）共用的審核流程規則。

---

## 🔄 三省審核流程

三省之間的狀態流轉遵循以下路徑：

```
太子(Taizi) → 中書省(Zhongshu) → 門下省(Menxia) → 尚書省(Assigned)
                    ↑                    |
                    └────── 封駁退回 ──────┘
```

### 審核原則

1. **中書省**：負責規劃擬制，產出可執行方案
2. **門下省**：負責審核把關，確保方案可行且合規
3. **尚書省**：負責任務分配和最終匯總驗收
4. **太子**：負責消息分揀和最終回復

### 封駁機制

- 門下省審核不通過 → 退回中書省重新規劃（Menxia → Zhongshu）
- 尚書省覆審不通過 → 退回門下省覆核（Review → Menxia）
- 退回時**必須**附帶明確的駁回理由和修改要求

### 創建任務權限

只有太子和中書省可以創建新任務（`create` 命令）。門下省和尚書省不創建任務。
